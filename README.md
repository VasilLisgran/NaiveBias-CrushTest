# NaiveBias-CrushTest

Когда наивный байесовский классификатор (NB) «ломается» из-за коррелированных признаков? Синтетический стресс-тест: гауссовский NB против QDA (полная ковариация у каждого класса) на двух гауссовских классах.

## Вопрос и краткий итог

NB предполагает независимость признаков. Что происходит, когда они сильно коррелируют, и когда QDA, учитывающий корреляции, реально выигрывает?

**Что показывают рисунки.** Числа ниже взяты с рисунков репозитория (имя файла в скобках) или из массивов `.npy` (указано явно).

- **Сдвиг вдоль длинной оси эллипса** ($`\theta=0^\circ`$): при $`n=3200`$ разрыв $`\mathrm{QDA}-\mathrm{NB}`$ лежит в пределах от $`-0.009`$ до $`0`$ (`diff_vs_angle_angle_equi_shifts.png`, $`\rho=0.7`$). На малых выборках NB выигрывает у QDA: до $`-0.12`$ при $`n=50`$ (`diff_heatmaps_all.png`, центры $`\pm m\,\mathbf 1`$).
- **Сдвиг наискосок к осям:** NB проигрывает QDA. Максимум по углу ≈0.17 при $`\rho=0.7`$, $`D=8`$, $`s=0.7`$ (`diff_vs_angle_angle_equi_shifts.png`); при сдвиге по одному признаку ≈0.24 при $`\rho=0.9`$ (`diff_vs_n_e1_equi.png`). С ростом $`n`$ до 3200 проигрыш на этих рисунках не исчезает.
- **Классы различаются только ковариациями:** NB остаётся на уровне 0.5, QDA при $`\rho=0.9`$ достигает 0.85–0.98 в зависимости от $`D`$ (`acc_vs_rho_cov_diff.png`).

Почему так (нулевой разрыв при сдвиге вдоль собственного вектора $`\Sigma`$) объясняет раздел «Теория»; он выведен в этом README и сверен с массивами (таблицы в разделах 3–5).

## Что такое «сдвиг», «направление» и угол θ

Центры двух классов стоят в точках $`+\mathbf m`$ и $`-\mathbf m`$. Стрелка между ними и есть «сдвиг». У неё два свойства:

- **длина** $`s=\|\mathbf m\|`$ — расстояние от начала координат до центра каждого класса (в скриптах `sh_g`); расстояние между центрами равно $`2s`$;
- **направление** — единичный вектор $`\mathbf d=\mathbf m/s`$, то есть куда смотрит стрелка.

Если признаки коррелируют, облако каждого класса — вытянутый эллипс. Его оси — собственные векторы матрицы $`\Sigma`$, то есть направления, вдоль которых $`\Sigma`$ вектор только растягивает или сжимает и не поворачивает. Для равнокоррелированной $`\Sigma`$ (все внедиагональные элементы равны $`\rho`$) длинная ось — это $`\mathbf u=\frac{1}{\sqrt D}(1,\dots,1)`$ (собственное значение $`1+(D-1)\rho`$), а все направления, перпендикулярные $`\mathbf u`$, — короткие оси (собственное значение $`1-\rho`$). Пример для $`D=2`$, $`\rho=0.9`$:

```math
\Sigma\begin{pmatrix}1\\1\end{pmatrix}=1.9\begin{pmatrix}1\\1\end{pmatrix},\qquad
\Sigma\begin{pmatrix}1\\-1\end{pmatrix}=0.1\begin{pmatrix}1\\-1\end{pmatrix},\qquad
\Sigma\begin{pmatrix}1\\0\end{pmatrix}=\begin{pmatrix}1\\0.9\end{pmatrix}.
```

Первые два вектора $`\Sigma`$ только растягивает (это оси эллипса), третий она поворачивает к диагонали (это не ось).

В угловых экспериментах направление задаётся одним углом $`\theta`$:

```math
\mathbf d(\theta)=\cos\theta\,\mathbf u+\sin\theta\,\mathbf v,\qquad
\mathbf v=\frac{1}{\sqrt 2}(1,-1,0,\dots,0)\perp\mathbf u .
```

$`\theta`$ — это угол между направлением сдвига и длинной осью $`\mathbf u`$ (а не осью $`x_1`$). При $`\theta=0^\circ`$ центры разведены вдоль длинной оси, при $`\theta=90^\circ`$ — поперёк неё, между ними — наклонные направления. При $`D=2`$ угол $`\theta=45^\circ`$ даёт $`\mathbf d=(1,0)`$, то есть сдвиг только по $`x_1`$. В коде направление строится так: `main.py`, строки 111–119.

Как $`\theta`$ влияет на разрыв $`\mathrm{QDA}-\mathrm{NB}`$, показано в разделе 4 («Результаты»); почему — в разделе «Теория».

## Постановка

- **Данные.** Два класса $`\mathcal N(\boldsymbol\mu_1,\Sigma_1)`$ и $`\mathcal N(\boldsymbol\mu_2,\Sigma_2)`$, метки 0 и 1, классы сбалансированы.
- **Классификаторы** (в скриптах импортируются только `numpy` и `matplotlib`):
  - NB (`GaussianClassificator`): по каждому признаку отдельно оцениваются среднее и дисперсия, плотности перемножаются, приоры не используются;
  - QDA (`QuadraticDiscriminantClassificator`): среднее и полная ковариация на класс, логарифм плотности плюс логарифм приора.
- **Матрицы ковариации.**
  - Равнокоррелированная: $`\Sigma_{ii}=1`$, $`\Sigma_{ij}=\rho`$ при $`i\neq j`$.
  - Тёплица: $`\Sigma_{ij}=\rho^{|i-j|}`$.
  - Для случая «разные ковариации»: класс 1 имеет $`\rho^{|i-j|}`$, класс 2 имеет $`(-\rho)^{|i-j|}`$ (знаки связей чередуются); в `main_mod.py` это `Cov_first` и `Cov_second`.
- **Сетка.** Размерность $`D\in\{2,4,6,8\}`$; размер выборки $`n\in\{50,100,200,400,800,1600,3200\}`$ точек на класс (данные перемешиваются, затем 80% идёт в обучение и 20% в тест); $`\rho`$ от 0 до 0.9 с шагом 0.1; 20 сидов. Значения заданы в начале скриптов (`correlations`, `dimensions`, `data`, `n_seeds`), разбиение на обучение и тест — функция `train`.

![Пример данных](Figure_1.png)

*Пример данных: две двумерные выборки, по одной на панель; центры примерно в $`(-1,-1)`$ и $`(1,1)`$. Значения $`\rho`$ и $`n`$ на рисунке не подписаны, скрипта для него в репозитории нет.*

**Метрика.** Accuracy на тесте. Для каждого сида считается разность $`\Delta_s=\mathrm{acc}^{\mathrm{QDA}}_s-\mathrm{acc}^{\mathrm{NB}}_s`$, на графиках показано её среднее по сидам и стандартная ошибка:

```math
\bar\Delta=\frac1N\sum_{s=1}^{N}\Delta_s,\qquad
\mathrm{SE}=\frac{\mathrm{std}(\Delta_s;\ \mathrm{ddof}=1)}{\sqrt N},\qquad N=20 .
```

Здесь $`N`$ — число сидов (`n_seeds`), а не число точек; в коде `se_diff = final_matrix.std(axis=1, ddof=1) / np.sqrt(n_seeds)`. SE показывает, насколько среднее по сидам могло бы отличаться из-за случайности данных; это не ошибка классификатора (она равна $`1-\mathrm{acc}`$). На графиках углового эксперимента и `cov_diff` закрашена полоса $`\pm 2\,\mathrm{SE}`$ (`main.py`, строки 233–235; `main_mod.py`, строки 148–150). На тепловых картах точками отмечены клетки, где $`|\bar\Delta|<2\,\mathrm{SE}`$, то есть разница неотличима от нуля (так сказано в заголовках рисунков). Скриптов для рисунков `diff_vs_n_*` в репозитории нет, их полосы выглядят так же, но ширина не подтверждена кодом.

## Результаты

### 1. Базовая геометрия: центры $`\pm m\,\mathbf 1`$; равные $`\rho`$

**Условия.** Центры классов $`\pm m\,\mathbf 1`$, $`\mathbf 1=(1,\dots,1)`$; $`m=i/10`$, $`i=0,\dots,9`$: ось «Сдвиг центра» на тепловых картах идёт от 0 до 0.9, в `main.py` это `centers = range(0, 10)` и `np.array(centers) / 10`. $`\Sigma`$ равнокоррелированная. Сдвиг вдоль $`\mathbf 1`$ — это $`\theta=0^\circ`$.
На `diff_heatmaps.png` значение $`n`$ не подписано: по журналу (`math.txt`) это $`n=800`$ (формулировка журнала — «800 обучающих объектов на класс»; в коде `data` — число точек на класс до разбиения 80/20), и картинка совпадает с колонкой $`n=800`$ на `diff_heatmaps_all.png`.

**Результат.** `diff_heatmaps.png` ($`n=800`$): красных клеток нет, кроме единичных бледно-розовых (≲0.005); наибольший проигрыш QDA ≈−0.025 при $`D=6`$ (сдвиг 0.1, $`\rho\ge0.5`$), при $`D=8`$ ≈−0.015, при $`D=2`$ и $`D=4`$ слабее. Вывод журнала: «QDA нигде не лучше NB» (`math.txt`, строка 37). `diff_heatmaps_all.png`: при $`n=50`$ проигрыш доходит до ≈−0.12 ($`D=4`$ и $`D=8`$) и при $`D\ge4`$ заметно больше, чем при $`D=2`$; при $`n\ge1600`$ клетки светлые (разница ≲0.02 по модулю).

**Объяснение.** Если центры лежат на оси эллипса, картина симметрична, и лучшая разделяющая линия совпадает с линией NB (перпендикуляр к отрезку между центрами): разрыв ноль при бесконечной выборке. Если центры не на оси, лучшая линия наклонена, а NB проводит свою перпендикулярно отрезку, и проигрывает (пример: 0.84 против 0.99 при ρ=0.9)..

### 5. Разные ковариации у классов ($`+\rho`$ против $`-\rho`$), средние одинаковые

## Теория (кратко)

Раздел не взят из `math.txt` (там этих формул нет): он выведен для объяснения результатов и проверен численно по таблице раздела 3, ячейке раздела 4 и значению 0.856 в разделе 5.

Пусть средние классов $`\pm\mathbf m`$, общая ковариация $`\Sigma`$, равные приоры, дисперсии признаков равны 1. При бесконечной выборке:

```math
\mathrm{acc}_{\mathrm{Bayes}}=\Phi\!\left(\sqrt{\mathbf m^{\top}\Sigma^{-1}\mathbf m}\right),\qquad
\mathrm{acc}_{\mathrm{NB}}=\Phi\!\left(\frac{\mathbf m^{\top}\mathbf m}{\sqrt{\mathbf m^{\top}\Sigma\,\mathbf m}}\right),
```

где $`\Phi`$ — функция распределения стандартного нормального. По неравенству Коши–Буняковского

```math
(\mathbf m^{\top}\mathbf m)^2\le(\mathbf m^{\top}\Sigma\,\mathbf m)(\mathbf m^{\top}\Sigma^{-1}\mathbf m),
```

причём равенство достигается тогда и только тогда, когда $`\mathbf m`$ — собственный вектор $`\Sigma`$. То есть разрыв $`\mathrm{acc}_{\mathrm{Bayes}}-\mathrm{acc}_{\mathrm{NB}}\ge 0`$ равен нулю ровно в этом случае.

**Сдвиг вдоль одного признака.** Для $`\mathbf m=c\,\mathbf e_k`$

```math
\mathrm{acc}_{\mathrm{Bayes}}-\mathrm{acc}_{\mathrm{NB}}=\Phi\!\left(c\sqrt{(\Sigma^{-1})_{kk}}\right)-\Phi(c).
```

- Матрица Тёплица $`\rho^{|i-j|}`$: $`\Sigma^{-1}`$ трёхдиагональна, $`(\Sigma^{-1})_{kk}=\dfrac{1}{1-\rho^2}`$ для крайнего признака и $`\dfrac{1+\rho^2}{1-\rho^2}`$ для среднего. При $`\rho=0.9`$, $`c=0.3`$ получаем 0.136 для крайнего и 0.205 для среднего, что согласуется с таблицей из раздела 3 (0.132–0.138 и 0.199–0.205).
- Равнокоррелированная матрица: $`(\Sigma^{-1})_{kk}=\dfrac{1+(D-2)\rho}{(1-\rho)\,(1+(D-1)\rho)}`$; при $`\rho=0.9`$, $`c=0.3`$ это 0.136, 0.177, 0.189, 0.195 для $`D=2,4,6,8`$.

**Два класса с $`+\rho`$ и $`-\rho`$.** При $`D=2`$ и нулевых средних правило Байеса сводится к знаку $`x_1x_2`$, откуда

```math
\mathrm{acc}_{\mathrm{Bayes}}=\frac12+\frac1\pi\arcsin\rho .
```

## Ограничения

- Только гауссовские данные, сбалансированные классы, $`D\le 8`$, два семейства матриц ковариации (равнокоррелированная и Тёплица) в основных экспериментах (`dimensions`, раздел «Постановка»).
- 20 сидов (`n_seeds`). $`n`$ — число точек на класс до разбиения (`data`); данные перемешиваются, затем 80% идёт в обучение, 20% в тест (`train`), поэтому при $`n=50`$ тест состоит всего из 20 точек.
- NB считает дисперсию через `np.var` (делитель $`n`$, строка 55 в `main.py`), QDA — ковариацию через `np.cov` (делитель $`n-1`$, строка 17); у NB нет приоров (классы сбалансированы).
- Вектор $`\mathbf v`$ в угловом эксперименте фиксирован как $`(1,-1,0,\dots,0)/\sqrt2`$ (`main.py`, строка 115); другие варианты $`\mathbf v`$ в репозитории не исследованы.
- Рисунки углового эксперимента построены только для $`\rho=0.7`$ (`j_rho`); массивы содержат все десять значений $`\rho`$.
- Остаток 0.01–0.03 на $`\theta=90^\circ`$ при малом $`s`$ в равнокоррелированном случае теорией не предсказан и в репозитории не изучен (раздел 4).
