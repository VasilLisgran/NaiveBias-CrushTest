# NaiveBias-CrushTest
 
Когда наивный байесовский классификатор (NB) «ломается» из-за коррелированных признаков? Синтетический стресс-тест: гауссовский NB против QDA (полная ковариация у каждого класса) на двух гауссовских классах.

## Вопрос и главный вывод
 
NB предполагает независимость признаков. Что происходит, когда они сильно коррелируют, и когда QDA, учитывающий корреляции, реально выигрывает?
 
**Главный вывод.** Сама по себе корреляция признаков не делает NB плохим. NB теряет в точности ровно ту часть различия между классами, которая «спрятана» в зависимостях между признаками:
 
- если классы различаются сдвигом средних вдоль направления, по которому ковариационная матрица только растягивает пространство (собственный вектор Σ), NB при большой выборке не уступает QDA, а на малой выборке выигрывает у него;
- если сдвиг лежит в других направлениях, NB проигрывает QDA до 0.24–0.30 по accuracy, и этот проигрыш не исчезает с ростом выборки;
- если классы различаются **только** ковариациями (одинаковые средние и дисперсии), NB остаётся на уровне случайного угадывания (≈0.5), а QDA достигает 0.85–0.98.
При малых выборках картина обратная: гибкая модель (QDA) платит за оценку ковариаций и проигрывает простой.
 
## Постановка
 
- **Данные.** Два класса `N(μ₁, Σ₁)` и `N(μ₂, Σ₂)`, метки 0 и 1, классы сбалансированы.
- **Классификаторы** (реализованы на numpy, без sklearn):
  - NB — гауссовский, по каждому признаку отдельно оцениваются среднее и дисперсия, плотности перемножаются;
  - QDA — среднее и полная ковариация на класс, логарифм плотности плюс логарифм приора.
- **Матрицы ковариации.** Равнокоррелированная (все внедиагональные элементы равны ρ) и Тёплица `Σᵢⱼ = ρ^|i−j|`; для случая «разные ковариации» классы получают `+ρ` и `−ρ` (знаки чередуются).
- **Сетка.** Размерность D ∈ {2, 4, 6, 8}; размер выборки n ∈ {50, 100, 200, 400, 800, 1600, 3200} точек на класс (80% идёт в обучение, 20% в тест); ρ от 0 до 0.9 с шагом 0.1; 20 сидов.
- **Метрика.** Accuracy на тесте; для сравнения берётся разность `QDA − NB`, усреднённая по сидам. Стандартная ошибка `SE = std(ddof=1)/√20`, на графиках полоса ±2·SE, на тепловых картах точками отмечены клетки с `|среднее| < 2·SE`.

## Результаты
 
### 1. Базовая геометрия: центры ±m·(1,…,1); равные ρ
 
QDA практически нигде не выигрывает у NB: `QDA − NB ≤ 0` в пределах шума. На выборке n = 800 на класс (так указано в журнале, `diff_heatmaps.png`) проигрыш QDA достигает −0.025 (D = 6), при n = 50 до −0.12, при n ≥ 1600 разница около нуля (не хуже −0.01). Проигрыш растёт с размерностью и дольше держится при высокой корреляции. При n → ∞ это согласуется с теорией: сдвиг вдоль (1,…,1) для равнокоррелированной Σ идёт вдоль собственного направления (см. «Теория»); проигрыш на малых n по-видимому является ценой оценки ковариаций у QDA.
 
`diff_heatmaps.png`, `diff_heatmaps_all.png`; точность отдельных классификаторов для одного сида: `Naive-Bias-one-seed.png`, `QDA-one-seed.png`; пример данных при D = 2: `Figure_1.png`.

### 2. Матрица Тёплица вместо равных ρ
 
Те же кривые обучения `QDA − NB` по n для нескольких пар (сдвиг, ρ): при n = 50–200 QDA уступает NB (до 0.1 при D = 8), при n ≥ 800 разница около нуля. `diff_vs_n_toeplitz.png`.
 
### 3. Сдвиг по одному признаку
 
Центры ±c·eₖ, остальные координаты нулевые.
 
- **Равнокоррелированная Σ, сдвиг по первому признаку** (`diff_vs_n_e1_equi.png`): NB теряет до **0.24** (D = 8, ρ = 0.9, сдвиг 0.5, n = 3200). Потеря не исчезает с ростом n, растёт с ρ и с D; при ρ = 0 равна нулю.
- **Тёплиц, сдвиг по первому и по второму признаку** (`diff_vs_n_toep_e1.png`, `diff_vs_n_toep_e2.png`). При ρ = 0.9, сдвиге 0.5 и n = 3200:
| Сдвигается | D = 2 | D = 4 | D = 6 | D = 8 |
|---|---|---|---|---|
| первый признак (крайний) | 0.182 | 0.179 | 0.177 | 0.181 |
| второй признак (средний) | 0.183 | 0.244 | 0.241 | 0.247 |
 
Признаки у Тёплица неравноправны: диагональные элементы Σ⁻¹ у крайнего и у среднего признака разные (`1/(1−ρ²)` и `(1+ρ²)/(1−ρ²)`), поэтому потери NB разные.
 
### 4. Угол сдвига относительно структуры Σ
 
Направление сдвига `d(θ) = cosθ·u + sinθ·v`, где `u = (1,…,1)/√D`, а `v` перпендикулярно `u` (в скриптах `v = (1, −1, 0, …, 0)/√2`). Длина сдвига фиксирована (0.1, 0.3, 0.5, 0.7), θ от 0° до 90°.
 
- **Равнокоррелированная Σ** (`main.py`, `diff_vs_angle_angle_equi_shifts.png`): на краях (θ = 0° и 90°) разрыв почти нулевой, максимум около 45–60°. При ρ = 0.7, сдвиге 0.7, n = 3200 максимум равен 0.078 (D = 2), 0.126 (D = 4), 0.148 (D = 6), 0.167 (D = 8). Наибольшее значение по всей сетке: **0.304** (D = 8, сдвиг 0.7, θ = 45°, ρ = 0.9).
- **Проверка теорией.** Контрольная клетка D = 8, сдвиг 0.5, θ = 45°, ρ = 0.7, n = 3200: теория (бесконечная выборка) 0.1341, симуляция 0.1334 ± 0.0035.
- **Тёплиц** (`degree_toeplitz.py`, `diff_vs_angle_angle_toep_shifts.png`): та же форма горба. При ρ = 0.7, сдвиге 0.7, n = 3200 максимум около 45° равен 0.078, 0.128, 0.145, 0.156 для D = 2, 4, 6, 8. При D = 2 результаты совпадают с равнокоррелированным случаем (матрицы одинаковы). При D ≥ 4 на θ = 90° остаётся разрыв 0.017–0.023, потому что `v` не собственное направление матрицы Тёплица.
- **Конечный n.** На θ = 90° при больших D и ρ разрыв положителен и убывает с ростом n (шум оценки у NB); на малых углах при малом n QDA платит за оценку ковариаций (отрицательный разрыв).
- `diff_vs_angle_angle_equi.png` — более ранняя версия с фиксированной длиной сдвига 0.3.
![diff_vs_angle_angle_toep_shifts](diff_vs_angle_angle_toep_shifts.png)
 
### 5. Разные ковариации у классов (+ρ против −ρ), средние одинаковые
 
`main_mod.py`, `acc_vs_rho_cov_diff.png`. Классы различаются только знаком связей между соседними признаками, одиночные распределения признаков одинаковы.
 
- **NB:** accuracy около 0.5 при любых ρ, D и n (среднее по всей сетке 0.502).
- **QDA, n = 3200:** D = 2: 0.853 при ρ = 0.9 (теория `1/2 + arcsin(ρ)/π` = 0.856); D = 4: 0.931; D = 6: 0.965; D = 8: 0.983.
- QDA растёт с ρ и с D; при малых n отстаёт от своего предела, но уже при n = 400 близок к нему.

## Теория (кратко)
 
Пусть средние классов ±m, общая ковариация Σ, равные приоры, дисперсии признаков равны 1. При бесконечной выборке:
 
```
точность идеального классификатора  = Φ( √(mᵀ Σ⁻¹ m) )
точность наивного байеса            = Φ( mᵀm / √(mᵀ Σ m) )
```
 
где Φ — функция распределения стандартного нормального. По неравенству Коши–Буняковского `(mᵀm)² ≤ (mᵀΣm)(mᵀΣ⁻¹m)`, равенство достигается тогда и только тогда, когда `m` — собственный вектор Σ. То есть разрыв равен нулю ровно в этом случае. Для сдвига вдоль одного признака `m = c·eₖ` разрыв равен `Φ(c·√(Σ⁻¹)ₖₖ) − Φ(c)`; при ρ = 0.9, c = 0.5 это 0.183 для крайнего и 0.247 для среднего признака Тёплица, что совпадает с таблицей выше. Для двух классов с `+ρ` и `−ρ` при D = 2 правило Байеса сводится к знаку `x₁·x₂`, откуда точность `1/2 + arcsin(ρ)/π`.
 
## Как воспроизвести
 
```
pip install numpy matplotlib
python main.py              # углы, равнокоррелированная Σ (около 3 минут)
python degree_toeplitz.py   # углы, матрица Тёплица (около 3 минут)
python main_mod.py          # +ρ против −ρ (около 10 секунд)
```
 
Время указано по проверочному запуску на машине с двумя ядрами. Параметры (`correlations`, `dimensions`, `data`, `n_seeds`, `shifts_grid`, `degrees_grid`, `tag`) заданы в начале каждого скрипта. Скрипты сохраняют рисунки `.png` и массивы `.npy` (`mean_*` и `se_*`) в текущую папку; при запуске открывается окно `matplotlib` (в окружении без экрана задайте `MPLBACKEND=Agg`). В `main.py` и `degree_toeplitz.py` массивы сохраняются после `plt.show()`, то есть после закрытия окна рисунка.
 
Формы массивов:
 
- `mean_diff_angle_*.npy`: `(n, D, сдвиг, угол, ρ)`;
- `mean_diff_e1_equi.npy`, `mean_diff_toep_e1.npy`, `mean_diff_toep_e2.npy`: `(n, D, сдвиг, ρ)`, сдвиг = индекс/10;
- `mean_nb_cov_diff.npy`, `mean_qda_cov_diff.npy`: `(n, D, ρ)`, точности NB и QDA отдельно.

## Ограничения
 
- Только гауссовские данные, сбалансированные классы, D ≤ 8, два семейства матриц ковариации.
- 20 сидов; тест это 20% выборки, поэтому при n = 50 на класс он состоит из 20 точек и шум велик. Здесь n означает размер выборки на класс до разбиения: в обучение идёт около 80%.
- В скриптах NB считает дисперсию через `np.var` (делитель n), а QDA ковариацию через `np.cov` (делитель n−1); приоров у NB нет (при равных классах это не влияет на решение).
- Выбор вектора `v` в угловом эксперименте проверен на равнокоррелированной матрице (другой `v` с чередующимися знаками даёт тот же результат в пределах шума; этот прогон в репозиторий не входит); на матрице Тёплица `v` не проверялся.
- Объяснение шума NB на θ = 90° при больших D и ρ (шум оценки при коррелированных нерелевантных признаках) остаётся гипотезой: согласуется со спадом с ростом n, но прямо не доказано.
- Результаты немного различаются между машинами из-за разложения матрицы в `multivariate_normal`; побитовой воспроизводимости между машинами нет.
